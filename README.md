# 애플트랙 (AppleTrack) by FarmBridge

사과의 **처음 품질**과 **저장 중 변화**를 계산해 보여 주고, 직접 잰 값과 비교·기록하는 웹 서비스입니다.
원예특작과학원 멘토링을 바탕으로 5조 팜브릿지가 만들었습니다.

- 사이트: https://trackap.netlify.app
- 계산은 **시연용**이며 정확도가 아직 검증되지 않았습니다. 출하·안전 여부를 판정하지 않습니다.

## 주요 기능

| 구분 | 기능 |
| --- | --- |
| 새 사과 등록 | 지도에서 산지를 골라 시작하거나 직접 잰 값으로 시작합니다. 품종, 수확일, 보관 조건 등을 입력합니다. |
| 처음 품질 추정 | 수확한 해의 농업기상 관측자료를 산지별 회귀식에 넣어 추정합니다. 조회가 실패하면 재시도할 수 있고, 자료가 부족해도 실측값으로 계산을 시작할 수 있습니다. |
| 저장 중 변화 | 단단함·당도·산도·무게 감소를 저장 일수별로 계산합니다. 그래프에서 계산값은 선, 실측값은 동그라미, 고른 날짜는 세로선으로 표시합니다. |
| 측정 비교 | 실측을 추가하면 이후 계산에 반영합니다. 측정한 날의 값과 그날 이전까지의 기록으로 계산한 값을 비교할 수 있습니다. |
| 목표 저장일·캘린더 | 목표일의 예상 단단함과 당도를 확인하고 캘린더에 가져올 일정 파일(`.ics`)을 내려받습니다. |
| 기록 관리 | 저장 중·출하 완료 기록을 분리해 볼 수 있습니다. 100건을 넘어도 등록할 수 있으며, 목록은 나눠 불러오고 조회 권한이 있는 이전 기록은 상세 주소로도 열 수 있습니다. |
| 시세 | 서울 가락시장 사과 경매가를 10kg 기준으로 환산해 보여 줍니다. |
| 농가 편의 | 글자 크게, 휴대폰 홈 화면 추가(PWA), N↔kgf 환산, 상자 수 환산, 내 단단함 기준 도달 시기, CSV 내려받기를 지원합니다. |
| 비회원 체험 | `/try`에서 예시 사과를 보거나 내 사과 조건을 입력해 저장 없이 결과를 확인할 수 있습니다. |
| 계정 | 아이디·비밀번호 가입, 비밀번호 변경, 회원 탈퇴, 개인정보처리방침(`/privacy`)·이용약관(`/terms`) |

## 계산 근거와 적용 범위

| 품종 | 처음 품질(날씨) | 저장 중 변화 | 계산 범위 |
| --- | --- | --- | --- |
| 홍로 | 거창·장수·충주·군위·포천·화성 | 팀 엑셀 근사식(유진기 외 2018, 거창 0℃·4℃ 저장 연구 기반) | 일반 저온·1-MCP 미처리·0℃/4℃, 최대 120일 |
| 후지 | 청송·장수·영주·충주·군위·포천·화성 | 팀 엑셀 식(일반 저온·1-MCP·CA) | 최대 300일 계산, 상세 그래프 기본 200일. 선택한 날짜에 맞춰 계산 범위 안에서 확장합니다. CA+1-MCP 처리는 준비 중입니다. |

- 기상 변수는 4월 또는 4~5월 일최저기온 평균, 5~6월과 7~8월의 (일평균기온 − 5℃) 합, 산지별 8월 또는 9월 누적 강수량입니다.
- 농촌진흥청 국립농업과학원의 농업기상 관측자료를 공공데이터포털 API로 가져옵니다. 자료가 부족했던 기록은 해당 산지의 집계 월이 끝난 뒤 다시 조회하며, 필요한 관측값이 모두 들어오면 계산합니다. 예를 들어 포천은 8월 강수량을 사용하므로 9월부터 재조회할 수 있습니다.
- 수확일보다 늦게 끝나는 관측 기간을 쓰는 산지는 수확 이후 강수량도 추정에 포함될 수 있습니다.
- 색 변화·저장 장해는 예측하지 않습니다.
- 식·계수·출처 대조는 [docs/model-sources.md](docs/model-sources.md), 원자료는 `data/` 폴더에 있습니다.

## 기술 구성

- Next.js 16, React 19, TypeScript
- Supabase(인증·데이터베이스·파일 저장, 서울 리전), Netlify 배포
- three.js(3D), GitHub Actions(자동 테스트)

```
app/            화면(내 사과, 체험 /try, 처리방침 /privacy, 약관 /terms)과 API 경로
components/     화면 구성 요소(my-apples, new-apple, mini-charts, lot-preview 등)
lib/            계산 엔진(quality-models, initial-quality, hongro, lot-predict, rda-weather)
supabase/       데이터베이스 SQL(날짜순)
data/           회귀식·저장식 원자료와 근거 문서
docs/           모델 출처(model-sources.md), archive/는 이전 작업 기록
tests/          단위 테스트, tests/browser는 브라우저 테스트
```

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
```

`.env.local`에 아래 값을 넣습니다. **비밀키는 Git에 올리지 마세요.**

```dotenv
NEXT_PUBLIC_SUPABASE_URL=<Supabase 프로젝트 URL>
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<publishable key>
SUPABASE_STORAGE_BUCKET=fruitroom_files
RDA_SERVICE_KEY=<공공데이터포털 농업기상 인증키, 서버에서만 사용>
```

AI 도우미 코드는 남아 있지만 `AI_*` 환경변수를 넣지 않아 꺼져 있습니다.

### 데이터베이스

새 Supabase 프로젝트라면 `supabase/` 폴더의 SQL을 파일 이름(날짜) 순서대로 실행합니다. 첫 파일 `2026-10-01_base_tables.sql`이 사과·측정·파일 등 기본 테이블을 만들고, 이후 파일이 권한 규칙(RLS)·프로필·함수를 더합니다. 파일 저장소 버킷(`fruitroom_files`, 비공개)은 Supabase Storage에서 만듭니다.
가입은 아이디 방식이므로 Supabase Authentication → Email의 **Confirm email을 꺼 두어야** 합니다.
