# 애플트랙 계산 연결 검토

검토 기준: 사용자 제공 최신 `fruitroom_team-main(3).zip`, 2026-10-26 수정본.

## 소스에서 확인한 기존 문제

- 홍로 전용 계산과 후지 공통 추적 계산이 분리되어 있었고, AI 경로는 홍로를 일괄 차단했다.
- 실측 감모율의 표본 검증 규칙이 모델 감모율에도 적용되어, 실측 중량이 없거나 실제 물량인 경우 후지 모델 곡선까지 차단했다.
- 후지 1-MCP 경도는 이전 번들 엑셀의 이차식을 사용했으나 최신 제공 엑셀의 명시 수식은 초기값 유지식이다.
- 홍로 기록 저장은 입력된 CA/1-MCP 조건을 일반 저온/미처리로 바꾸고 추적 표본 정보를 삭제했다.
- AI 비교 기준의 서명에는 저장 온도와 후지 참고 추정 선택이 포함되지 않았다.

## 수정된 연결 구조

`lib/quality-models.ts`의 레지스트리가 모델 식, 단위, 버전, 출처, 표시 범위와 검증 상태를 함께 관리한다. `predictQuality`가 항목별 계산값과 계산 불가 이유를 반환한다. 값이 없으면 `null`이며, 실제로 계산한 0과 구분한다.

- 기존 후지 `storageValue`와 추적 그래프는 공통 엔진으로 연결된다.
- 홍로 API 호환 계산기도 동일한 홍로 모델 식을 호출한다. 홍로를 모르는 구형 후지 계산 경로는 홍로를 계속 명시적으로 거부하므로 자동 품종 대체가 발생하지 않는다.
- 실측 감모율은 동일 표본 ID·중량·측정일을 확인하는 별도 경로다. 모델 감모율은 저장 시작일부터 누적한 모델 값이다. 초기 중량 입력과 무관하게 계산한다.
- 3D에는 별도 수식을 복제하지 않고 해당 날짜의 품질 결과와 감모율 결과를 전달한다. 외관 변형의 강도와 메시 변형은 `lib/apple-appearance.ts`가 담당한다.
- CSV 다운로드는 `lib/quality-export.ts`의 순수 생성 함수를 직접 호출한다. 선택 결과, 날짜별 그래프 점, 실측 기록, 고정 비교 기준을 이 함수에서 내보내며 실제 생성 함수를 대상으로 검증한다.
- 홍로 CA/1-MCP 등의 실제 입력은 기록으로 보존하되, 지원하지 않는 조합의 예측은 계산 불가로 반환한다.
- AI 설명은 모델 결과와 실측 감모율을 서로 다른 필드로 제공한다. 저장된 물량과 요청 품종이 다르면 명시적으로 거부한다.

전체 실행과 화면 확인 결과는 최종 검증 문서를 따른다. 위 표는 검증 목적이며, 실측 사과를 이용한 예측 정확도 평가를 뜻하지 않는다.

## 해석과 검증의 한계

- 홍로 0~120일은 구현된 모델 표시 범위다. 상품성 유지 기간이나 안전한 보관 기간이 아니다.
- 홍로 저장식은 제공 엑셀의 근사식이다. 독립된 실제 과실 자료로 오차를 평가한 모델로 표시하지 않는다.
- 후지 최신 엑셀의 1-MCP 경도 E6은 유지식이고 C6 분류는 여전히 ‘2차’이다. 최신 명시 수식을 버전 선택 근거로 사용하되 파일 내부의 표기 불일치는 미해결로 남긴다.
- 후지 저장식의 온도와 검증 기간은 제공 자료에서 확인되지 않았다. 선택 온도나 센서 이력에 따른 보정은 하지 않는다.
- 외관 수축·주름은 설명용 변형이며 사진·부피·주름 실측으로 보정되지 않았다. 홍로 사진 기반 GLB를 후지의 실제 외형으로 표현하지 않는다.
- 소스 ZIP 수정과 운영 Netlify 배포는 별개다. 운영 배포 완료 여부는 실제 배포 결과로만 확인한다.
