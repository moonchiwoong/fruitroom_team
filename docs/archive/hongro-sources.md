## 3. 저장 변화식 원문과 비고 충돌

`거창_품질예측식.xlsx`의 E2:E7에는 다음 식이 텍스트로 기재되어 있습니다. `F0`, `A0`, `S0`는 각각 초기 경도, 초기 산도, 초기 당도이고 `t`는 저장 경과일입니다.

| 조건 | 지표 | 원문 동적 예측 수식 |
| --- | --- | --- |
| 0℃ 저온저장 | 경도 N | `F(t) = MAX(0, F0 - MIN(t, 60)*(7.0/60) - MAX(t-60, 0)*(7.4/60))` |
| 4℃ 저온저장 | 경도 N | `F(t) = MAX(0, F0 - MIN(t, 60)*(7.0/60) - MAX(t-60, 0)*(8.6/60))` |
| 0℃ 저온저장 | 산도 % | `A(t) = MAX(0, A0 - MAX(t-60, 0)*(0.05/60))` |
| 4℃ 저온저장 | 산도 % | `A(t) = MAX(0, A0 - MAX(t-60, 0)*(0.03/60))` |
| 0℃ 저온저장 | 당도 °Brix | `S(t) = S0` |
| 4℃ 저온저장 | 당도 °Brix | `S(t) = S0` |

확인한 충돌과 한계는 다음과 같습니다.

- 당도 E6/E7은 초기값 유지식이지만 C6/C7은 ‘초기값 고정 선형감쇄’, F6/F7은 120일 동안 약 0.4/0.3°Brix 감소라고 서술합니다. 수식과 비고가 일치하지 않습니다. 사용자 지시와 E열 수식에 따라 당도는 초기값 유지로 해석하며 감소 계수를 새로 만들지 않습니다.
- 경도 비고의 120일 값 53.6/52.4 N은 `F0=68.0 N`일 때의 값입니다. 산도 비고의 0.130/0.150% 역시 `A0=0.18%`일 때의 값입니다. 임의의 초기값에도 고정 적용되는 결과가 아닙니다.
- 원문에 0~60일과 60~120일 구간이 제시되어 있습니다. 사용자 지정 적용 범위는 홍로·거창, 0℃ 또는 4℃, 0~120일입니다. 이 범위를 논문으로 검증된 예측 정확도와 동일시하지 않습니다. 중간 온도 보간, 120일 초과 외삽, CA·1-MCP 조건은 이 자료로 뒷받침되지 않습니다.
- 중량과 횡경의 저장 중 변화식은 이 파일에 없습니다. 초기품질 항목의 수치를 저장 중 변화 모델로 확장할 근거가 아닙니다.

## 4. PDF의 실험 방법과 직접 확인 가능한 범위

논문: Yoo 등, “Effects of cold storage temperature treatments on fruit quality attributes in 'Hongro' apples”, *Korean J. Food Preserv.* 25(7), 779–785 (2018), DOI: `10.11002/kjfp.2018.25.7.779`.

### 재료·저장 조건 — PDF 2쪽, 논문 p780

- 경남 거창군 고제면과 경북 문경시 마성면의 과원에서 자란 `홍로/M.9` 9년생 나무의 과실입니다.
- 수확일은 2017-09-10이며, 외형적인 상처나 병반이 없는 과실을 선별했습니다.
- 저장 설정은 0℃와 4℃, 상대습도 90%이며 저장고 온도편차는 약 ±1℃입니다.
- 총 4개월 저장했고 수확 시, 저장 2개월 후(11월 10일), 3개월 후(12월 10일), 4개월 후(1월 10일)에 조사했습니다. 4개월은 달력상의 관측 일정이며, 정확히 120일 매일 관측했다는 뜻이 아닙니다.
- 과실 품질은 5개를 1반복으로 3반복, 총 15개 과실을 조사했습니다. 과피 장해 발생률의 표본은 별도로 총 120개입니다.

### 측정법 — PDF 2쪽, 논문 p780

- 경도: 직경 **11 mm plunger**를 장착한 rheometer `Compac-100Ⅱ` 사용. 적도부 과피를 제거하고 과실당 3회 측정한 평균을 **Newton(N)**으로 표시했습니다.
- 산도: 과즙 5 mL에 증류수 45 mL를 더하고 0.1 N NaOH로 pH 8.1까지 적정한 뒤 사과산으로 환산했습니다.
- 가용성 고형물: 디지털당도계 `PR-201α`로 측정했습니다.

### 초기값과 저장 결과 — PDF 3쪽/p781, PDF 4쪽/p782

Table 1의 거창 수확 시 경도는 68.0±0.5, 산도는 0.18±0.00%, 가용성 고형물은 12.6±0.07 °Brix입니다. 경도 열의 표기는 `N/Φ11 mm`이며, 본문의 측정법과 함께 읽어 탐침 직경 조건을 구분해야 합니다.

본문은 거창의 저장 4개월 후 경도 53.6 N(0℃), 52.4 N(4℃), 산도 0.13%(0℃), 0.15%(4℃)를 보고합니다. Fig. 2는 월별 측정 평균과 표준오차를 보여 줍니다. 이 관측점과 엑셀의 매일 계산하는 구간선형식을 동일한 검증 결과로 표시하지 않습니다. 논문은 경도·산도·가용성 고형물의 저장 온도 간 차이가 뚜렷하지 않았다고 설명하므로 두 수식의 수치 차이만으로 통계적으로 확정된 우열을 주장하지 않습니다.

## 5. 경도 단위 충돌과 남은 확인 사항

이미지는 `chang_Nmm`의 이름을 `경도(N/mm)`로 적고, 데이터 파일도 `chang_Nmm` 키를 사용합니다. 반면 저장식 엑셀은 `경도 (N)`, PDF 측정법은 Newton(N)와 Ø11 mm 탐침입니다. 사용자도 홍로 경도를 **N·Ø11 mm 기준**으로 명시했습니다.

사용자 지정 단위로 해석할 때에도 다음 구분을 보존합니다.

- 원본 키 `chang_Nmm`와 이미지의 `N/mm` 표기는 출처 기록에 남깁니다.
- 수치에 11을 곱하거나 나누지 않습니다. 탐침 직경은 측정 조건이며 자동 단위 변환 계수가 아닙니다.
- 사용자 지시는 홍로 자료에 적용됩니다. 기존 후지 초기품질 단위나 계수를 일괄 변경할 근거가 아닙니다.
- 초기품질 데이터는 사용자 설명에 따른 합성자료입니다. 합성값의 기초가 된 경도 자료의 측정기·원래 단위·측정 조건은 첨부만으로 독립 확인되지 않았습니다. PDF의 실측 방법을 합성데이터의 실제 측정 이력으로 표시하지 않습니다. 사용자 지정 N·Ø11 mm를 적용하면서도 이미지의 N/mm 표기가 생긴 경위는 남은 출처 확인 사항으로 구분합니다.

## 6. 자료를 결합할 때의 한계

기상 회귀식이 산출한 초기품질과 별개 실험에서 정리한 저장 변화식을 연결하는 것은 두 자료를 결합하는 계산입니다. **그 연결 전체를 검증한 독립 자료는 제공되지 않았습니다.** 새로운 학습·보정계수, RMSE·예측구간·신뢰구간을 이 자료만으로 추가하지 않습니다.

품종·산지·저장 온도·관측 시점·측정법의 근거는 위에서 확인한 범위에 한정됩니다. 생산연도·과원·성숙도·포장·습도·처리 방식 전반에 대한 일반화, 출하일·보관 가능일·식품 안전·가격 판단의 근거로 사용하지 않습니다.
