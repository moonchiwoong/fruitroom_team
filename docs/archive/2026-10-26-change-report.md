# 애플트랙 품종별 모델·3D 연결 변경 보고서

대상: 업로드된 `fruitroom_team-main(3).zip`. 검증일: 2026-10-26 (한국 시간).

이 파일은 수정 소스의 보고서입니다. 운영 Netlify 사이트 배포, 외부 저장소 커밋, 실제 고객 데이터 변경은 수행하지 않았습니다.

## 원래 구조와 운영 화면 대조

- `/try` → `GuestTry` → `QualityTracker` / `ModelInfo`가 체험·근거 화면입니다. 계정 화면도 같은 `QualityTracker`를 사용합니다.
- 기존 `lib/initial-quality.ts`의 `storageValue`, `lib/tracker.ts`의 `resolveModel`/`computeSeries`가 후지 계산을 담당했습니다. 별도 `lib/hongro.ts`와 `lib/hongro-tracker.ts`는 홍로 전용 계산을 담당했습니다.
- 기존 `quality-policy.ts`는 실제 입력의 모델 감모율까지 차단했습니다. 기존 3D 영역은 계산 품질과 분리된 외관 예시였습니다.
- 운영 URL `https://fruitroom.netlify.app/try?view=basis`를 브라우저에서 확인했습니다. ‘입력한 품종·산지별 차이’를 미반영 정보로 안내하고 후지 1-MCP 경도를 이차식으로 표시했습니다. 업로드 소스의 기존 공통 모델·근거 화면과 일치했지만, 최신 후지 엑셀의 유지식과는 달랐습니다. 홍로 전용 계산이 있던 최신 소스의 설명도 공통 화면에는 충분히 반영되지 않았습니다.

## 반영 모델

- 후지: 최신 `사과_품질예측_회귀식.xlsx`의 일반 저온·1-MCP·CA 모델. `fuji-xlsx-2026-10-26.1`.
- 후지 1-MCP 경도: 최신 Sheet1!E6 `F(t)=F0` 채택. 기존 번들 E6 이차식은 원본 파일에 보존했습니다. 최신 C6의 ‘2차’ 분류와 E6 유지식 간 불일치는 미해결로 표시했습니다.
- 홍로: `거창_품질예측식(1).xlsx`의 0℃·4℃ 일반 저온/1-MCP 미처리 경도·당도·산도 근사식. `hongro-xlsx-approximation-2026-10-26.1`. 0~120일만 표시합니다.
- 홍로 CA·1-MCP·다른 온도는 적용 모델 없음, 자체 감모율은 자료 부족입니다. 후지 일반 저온 감모율은 명시적 선택 시에만 홍로 미검증 참고 추정으로 표시합니다.
- 산도 0.18은 0.18%, 감모율 1.62084는 1.62084%입니다. 온도 보간·센서 보정·산지 배수·임의 시간 압축은 없습니다.
- 모든 모델은 독립 예측 정확도 검증 미완료입니다. 후지 300일과 홍로 120일은 표시 범위이며 상품성·안전 보관 기간이 아닙니다.

## 검증 환경의 한계

- 관리형 미리보기 명령은 Next.js가 받지 않는 개발 서버 인자를 추가하므로, 실제 GuestTry/3D 컴포넌트와 CSS를 별도 검증 번들로 구성해 브라우저에서 확인했습니다. Next.js 전체 서버 경로는 타입/테스트/프로덕션 빌드로 검사했습니다.
- 검증 브라우저는 WebGL 초기화를 지원하지 않았습니다. WebGL 실패 안내와 수치 표시 유지, 재시도 UI를 확인했고 실제 GLB 좌표 변형은 CPU 테스트로 확인했습니다. **GPU 렌더링·실제 마우스/터치 회전·줌, 날짜 변경 중 다운로드 횟수, 파일 404/파싱 실패 UI의 실브라우저 재현은 WebGL 가능한 기기에서 최종 확인이 필요합니다.** 구현에는 해당 처리와 캐시·자원 정리가 포함돼 있습니다.
- 실제 Supabase 계정 로그인·고객 기록 저장·권한, 운영 Netlify 배포 후 동작은 이 작업에서 실행하지 않았습니다. 자동 테스트는 격리된 입력과 fixture를 사용합니다.

## 추가로 필요한 자료

1. 홍로 자체 감모율 실측/모델, CA 및 1-MCP 처리 자료, 다른 온도에서의 검증 자료.
2. 후지 모델의 정확한 저장 온도·관측/검증 기간·예측 오차, 최신 MCP 경도 C6/E6 불일치 확인.
3. 수축·주름을 보정할 시간별 사진/3D 측정 자료와 후지 외형 모델.
4. 초기 기상 회귀 경도 N/mm와 저장 경도 N의 지표 동일성 확인 자료.

## 적용

ZIP을 풀고 Node.js 22.13 이상에서 `npm ci`, `npm run typecheck`, `npm test`, `npm run build`를 실행합니다. 기존 Supabase/Netlify 환경변수를 유지하고 기존 연결 저장소에 수정 소스를 반영해 배포합니다. 소스 ZIP 자체는 정적 배포용 빌드 결과가 아닙니다.
