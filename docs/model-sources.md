# 저장 품질 모델 출처 확인 및 변경 결정

확인일: 2026-10-26. 업로드한 최신 소스 ZIP과 원본 엑셀 2개, 논문 PDF, 홍로 3D 패키지의 실제 내용을 확인했다. 공개 사이트의 배포 커밋과 업로드 ZIP의 동일성은 별도 확인 사항이다.

## 원자료 보존

- `data/evidence/사과_품질예측_회귀식.xlsx`: 이번 요청에서 지정한 후지 저장 품질 식.
- `data/evidence/거창_품질예측식(1).xlsx`: 이번 요청에서 지정한 홍로 0℃·4℃ 저장 품질 근사식.
- `data/evidence/kjfp-25-7-779.pdf`: 홍로 저온저장 연구 원문.
- `data/evidence/source-manifest.json`: 위 원본들의 SHA-256, 크기, 엑셀 비어 있지 않은 셀의 전사와 기존 후지 파일의 비교 정보.
- 기존 `data/storage-quality-model.xlsx`는 과거 수식의 근거를 추적할 수 있도록 덮어쓰지 않고 보존했다.

## 후지 1-MCP 경도식의 출처 불일치

| 자료 | 위치 | 확인된 내용 |
| --- | --- | --- |
| 기존 소스의 `data/storage-quality-model.xlsx` | `Sheet1!E6` | `y = y0 - 0.002288*t + 0.00002365*t^2` |
| 이번 지정 자료 `사과_품질예측_회귀식.xlsx` | `Sheet1!E6` | `y = y0` |
| 이번 지정 자료의 모형 유형 | `Sheet1!C6` | 여전히 ‘초기값 고정 2차’로 표기됨 |
| 이번 지정 자료의 비고 | `Sheet1!F6` | 1-MCP 처리에 의한 연화 억제 곡선이라고 설명함 |

확인된 최신 지정 파일의 명시 수식 `E6`을 사용해 초기값 유지식으로 모델 버전을 구분한다. 기존 이차식을 근거 없이 삭제·재보정한 것이 아니다. 다만 최신 파일 자체의 유형 열과 수식 열이 불일치하므로, 유형 명칭이 잘못되었는지 수식이 의도적으로 바뀌었는지는 원저자 확인이 필요하다. 초기값 유지식의 예측 정확도를 검증한 것으로 표시하지 않는다.

두 후지 파일의 나머지 11개 항목 수식은 동일하다. 특히 일반 저온 감모율은 `0.007807*t + 0.0000475*t^2`이고 결과의 단위는 `%`다. 120일 결과는 `1.62084%`이다. 중량 입력이 없어도 이 시간 모델은 계산할 수 있다.

후지 파일에는 구체적인 저장 온도, 관측기간, 독립 검증기간·성능·논문 출처가 기재되어 있지 않다. 따라서 온도 보정·온도 범위의 검증을 주장하거나 화면 표시 기간을 검증된 적용 기간으로 설명해서는 안 된다. 현재 등록 조건과 이 불확실성을 화면에 함께 표시한다.

## 홍로 저장식 확인

`거창_품질예측식(1).xlsx`의 `Sheet1!E2:E7`은 요청한 식과 일치한다.

| 조건·항목 | 셀 | 명시 수식 |
| --- | --- | --- |
| 0℃ 경도 | E2 | `MAX(0, F0 - MIN(t,60)*(7.0/60) - MAX(t-60,0)*(7.4/60))` |
| 4℃ 경도 | E3 | `MAX(0, F0 - MIN(t,60)*(7.0/60) - MAX(t-60,0)*(8.6/60))` |
| 0℃ 산도 | E4 | `MAX(0, A0 - MAX(t-60,0)*(0.05/60))` |
| 4℃ 산도 | E5 | `MAX(0, A0 - MAX(t-60,0)*(0.03/60))` |
| 0℃ 당도 | E6 | `S(t) = S0` |
| 4℃ 당도 | E7 | `S(t) = S0` |

당도 유형/비고는 선형감쇄·0.4 또는 0.3°Brix 감소를 언급하지만 명시 수식은 고정식이다. 명시 수식을 우선하며 새 감소 계수를 만들지 않는다. 경도 비고의 53.6N·52.4N은 초기 경도 68N을 가정한 특정 결과이며, 임의 초기값에 그대로 적용하는 상수가 아니다. 산도 0.18은 0.18%이고 0.0018로 바꾸지 않는다.

0~120일은 이번 근사 모델의 표시·계산 범위다. 121일부터 외삽하지 않는다. 상품성 유지나 안전한 보관 기간을 보장하지 않는다. 홍로 CA·1-MCP 및 0℃·4℃ 사이 보간, 센서 온도 이력 보정, 감모율 예측식은 이 파일에 없다. 산지 입력에 따른 별도 계수도 없다.

## 홍로 감모율 식 추가 (2026-10-27)

사용자가 전달한 `data/evidence/홍로_품질예측식_감모율포함.xlsx` (SHA-256 `fd3196db6925adcc05cc2b033c615fe6adad641d50bf24c716929e494303b253`).

- `Sheet1!E2:E7`(경도·산도·당도 0℃·4℃)은 기존 `거창_품질예측식(1).xlsx`와 글자까지 같다.
- 새로 추가된 행: `A8:E8` 감모율(%) 0℃ 저온저장, 초기값 0, `y0(t) = 0.0215 * t (0 <= t <= 120)` / `A9:E9` 4℃, `y4(t) = 0.0272 * t`.
- 감모율 행에는 모형 유형(C열)과 비고(F열)가 비어 있어 관측 근거·표본·검증 정보가 없다. 120일 값은 0℃ 2.58%, 4℃ 3.264%.
- 기존 홍로 식과 같은 조건(일반 저온·1-MCP 미처리·정확히 0℃ 또는 4℃)에만 연결했다. 다른 온도·CA·1-MCP 처리에는 적용하지 않고, 이전의 ‘후지 식으로 참고 추정’ 경로는 제거했다(다른 품종 계수를 빌리지 않음).
- 모델 버전: `hongro-xlsx-approximation-2026-10-27.1`. 실측 감모율(같은 표본 중량)과는 별도로 표시한다.

## 홍로 논문과 엑셀 근사식의 구분

유진기 외(2018), 「저온저장 온도처리가 ‘홍로’ 사과의 저장중 과실품질에 미치는 영향」, 한국식품저장유통학회지 25(7), 779-785. DOI: `10.11002/kjfp.2018.25.7.779`.

- 인쇄 780쪽(파일 2쪽) 재료·방법: 2017-09-10 수확한 거창·문경 홍로, 설정 온도 0℃·4℃, 상대습도 90%, 온도편차 약 ±1℃, 저장 4개월. 수확 시와 저장 2·3·4개월에 품질을 조사했다. 이 온도편차는 1℃·2℃·3℃ 보간 모델의 근거가 아니다.
- 같은 쪽 경도 측정법: 껍질을 제거한 적도부를 직경 11mm 탐침으로 측정하고 힘을 N으로 표시했다. `N/Ø11 mm`는 탐침 조건을 병기한 것이며 N/mm 강성과 같은 단위가 아니다.
- 인쇄 781쪽(파일 3쪽) 표 1: 거창 수확 시 평균 경도 68.0N, 적정산도 0.18%, 가용성 고형물 12.6°Brix. 이 표의 평균값은 사용자 초기값의 대체 기본값이나 개별 과실의 확정값이 아니다.
- 인쇄 781쪽 본문과 782쪽 그림 2: 거창 4개월 경도 0℃ 53.6N·4℃ 52.4N, 산도 0℃ 0.13%·4℃ 0.15%를 보고한다. 그림은 측정 평균과 표준오차를 제시한다.
- 통계는 ANOVA, Duncan 다중검정 및 품질 항목 간 상관분석을 보고한다. 제공된 엑셀의 MAX/MIN 구간식이나 이를 독립 평가한 예측 RMSE·MAE·정확도는 직접 제시하지 않는다. 따라서 등록 식은 **논문 관측을 참고한 사용자 제공 엑셀 근사 모델**이며 논문이 직접 발표한 회귀식 또는 검증 완료 모델로 표시하지 않는다.
- 수확 시 과중은 표 1에 있지만 동일 표본의 시계열 중량 손실 모델은 제공하지 않는다. 과피 장해율·에틸렌·왁스 자료를 감모율로 바꾸거나 감모율/부패 외관의 계수로 사용하지 않는다.

## 홍로 3D 자료 확인

`Hongro_Apple_Blender_Package.zip`의 `Hongro_Apple/hongro_apple.glb`를 확인했다.

- glTF 2.0 바이너리. 노드/메시: `Hongro_Apple_Body`, `Hongro_Stem`.
- 위치·법선·UV가 있고 세 개의 PNG 텍스처가 GLB bufferView에 내장되어 있다. 외부 텍스처 다운로드 없이 GLB만으로 재질을 복원할 수 있다.
- 두 메시 모두 `targets`가 없다. 즉 GLB에 수축·주름 morph target은 없다. 별도의 웹 메시 변형 또는 실제 morph 추가가 필요하다.
- 패키지 README는 단일 저해상도 앞면 사진 기반 근사 모델이며 뒷면·깊이·밑면 형상은 추정이라고 명시한다. 임의 지름 약 80mm이며 정밀 스캔·실제 치수·품종 판정 자료가 아니다.
- 홍로를 지정한 사진 기반 모델이므로 후지에 사용할 때는 공통 설명용 모델임을 밝혀야 한다. 감모율과 수축·주름의 연결은 외관 실측으로 검증되지 않은 설명용 설정이다.

- 기존 `hongro-apple.glb`는 255×246 단일 사진을 늘린 텍스처라 화면에서 흐릿하게 보여 제거했다.

## 초기 경도 회귀식 단위 확인 (2026-10-31)
- 회귀식 작성자 확인: 날씨 기반 초기 경도 회귀식(거창 홍로, 청송·장수·영주 후지)의 경도 단위는 **N**이다. 계수 이미지·원자료 열 이름의 `N/mm`(`*_Nmm`) 표기는 오기.
- 따라서 단위 변환 없이 저장 모델의 경도(N) 처음 값으로 이어 계산한다. 이전의 ‘단위 확인 필요’ 경고와 후지 경도 미연결 처리는 해제했다.
