# 화면 사진

이 폴더의 사진은 3D로 그린 임시 사진입니다. 실제 사진으로 바꾸려면 **같은 파일 이름으로 덮어쓰면** 바로 적용됩니다.

| 파일 | 쓰이는 곳 | 권장 비율 |
|---|---|---|
| hero.webp | 홈 첫 화면 오른쪽 큰 사진 | 16:10 (예: 1600×1000) |
| storage.webp | 물량 관리 화면 | 16:10 |
| apple-1.webp ~ apple-3.webp | 사과(물량) 목록의 작은 사진 | 4:3 (예: 640×480) |

파일 이름이나 개수를 바꾸고 싶으면 `lib/photos.ts`의 경로를 고치면 됩니다. JPG·PNG도 쓸 수 있습니다.
